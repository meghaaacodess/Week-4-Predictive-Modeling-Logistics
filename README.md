# Week 4: Predictive Modeling and Optimization in Logistics

## Project Overview
This project demonstrates how machine learning can predict shipment delivery times and support logistics optimization using Python.

The project uses a hypothetical dataset containing 1,000 shipment records.

## Objectives
- Predict shipment delivery times.
- Compare machine learning algorithms.
- Evaluate model performance.
- Identify opportunities to improve logistics operations.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Models
- Linear Regression
- Decision Tree
- Random Forest

## Model Evaluation
Models are evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

The tuned Random Forest model achieved:
- MAE: 1.733 hours
- RMSE: 2.142 hours
- R²: 0.787

*Note: These results are based on simulated data and are illustrative.*
